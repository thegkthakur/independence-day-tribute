# Project Name
Independence Day Tribute

## Features
- Play/pause the anthem song
- Responsive Design
- Redirect to the section

## Tech Stack
Frontend:
- React
- Tailwind CSS
- JavaScript

## Installation

1. Clone the repository

git clone https://github.com/thegkthakur/independence-day-tribute.git

2. Install dependencies

npm install

3. Start the project

npm run dev
